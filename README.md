# منصتي للتحضير الذكي

واجهة تأسيسية عربية لإعداد تحضير دروس الفيزياء للصف الثالث الثانوي في ليبيا.

## تشغيل النسخة
- افتح `index.html` في متصفح حديث.
- لا تحتاج النسخة الحالية إلى تثبيت حزم أو خادم.

## ما يعمل حالياً
- واجهة عربية متجاوبة من اليمين إلى اليسار.
- إدخال بيانات الدرس.
- تقسيم الأهداف إلى معرفية ومهارية ووجدانية.
- إدخال التمهيد والشرح والنشاط والتقويم والواجب.
- حفظ التحضيرات محلياً في المتصفح باستخدام Local Storage.
- معاينة التحضير وطباعته.

## حدود النسخة الحالية
هذه نسخة أولية للواجهة وليست منصة إنتاج مكتملة:
- الحفظ محلي على الجهاز والمتصفح فقط، ولا توجد قاعدة بيانات أو مزامنة بين المستخدمين.
- لم يتم ربط نموذج ذكاء اصطناعي بعد.
- لم تُرفع أو تُعتمد الكتب والخطة الدراسية الرسمية بعد.
- تصدير Word وPDF كملفات مستقلة، وتسجيل الدخول والصلاحيات، تحتاج مراحل تطوير لاحقة.
- بيانات الوحدات والدروس ليست مستوردة من المنهج بعد.

## بنية المشروع
- `index.html`: هيكل الواجهة.
- `style.css`: التنسيق والتصميم.
- `app.js`: التفاعلات والحفظ والمعاينة والطباعة.

## ملاحظة تربوية
يجب أن تكون الأهداف السلوكية قابلة للملاحظة والقياس، وتراجع التحضيرات وفق المراجع الرسمية المعتمدة قبل استخدامها.
